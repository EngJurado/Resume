# i18n Translations and Theme/Language Button Controls

## Current state
- Translations for `sections.courses`, `sections.mertings`, and `sections.certifications` already exist in both `src/i18n/es.ts` and `src/i18n/en.ts`.
- `Courses.astro` and `Certifications.astro` already consume `translations` and render the localized headings.
- `Memberships.astro` also already uses `t.sections.memberships`.
- Header already contains `LanguageSelector.astro` (compact text links) and `DarkModeToggle.astro` (icon button).

## What needs to change
1. **Language control style**: Currently `LanguageSelector.astro` renders inline text links (`ES` / `EN`). The request is to present them as buttons instead of text links, while preserving the current behavior (navigate to `/es/` or `/en/`, save preference to `localStorage`, accessible labels).
2. **Theme control style**: `DarkModeToggle.astro` is already a `<button>` with icon-only display. The request is to add an explicit button to change the theme. This could mean keeping the icon button and adding a text label, or replacing the icon with a labeled button.

## Open question
**Button style preference**: Should the language and theme controls be:
- **Option A**: Compact icon buttons with `sr-only` text labels (minimal change from current)?
- **Option B**: Small outlined/filled buttons with visible text labels like "ES" / "EN" and "Light" / "Dark"?
- **Option C**: A dropdown menu button for each control?

Please confirm the preferred button style, and I will produce the detailed implementation plan.
