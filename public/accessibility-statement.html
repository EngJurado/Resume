Declaración de Accesibilidad

Sitio: https://engjurado.me

Fecha: 2026-08-09

Compromiso

Este sitio web está diseñado para ser accesible para todos los usuarios, incluyendo personas con discapacidades visuales, auditivas, motoras o cognitivas.

Estándares

Este sitio busca cumplir con las pautas de accesibilidad WCAG 2.1 nivel AA.

Características de accesibilidad implementadas

  • Estructura semántica HTML5
  • Navegación por teclado
  • Enlace para saltar al contenido principal (skip link)
  • Contraste de colores adecuado
  • Tipografía legible y redimensionable
  • Etiquetas ARIA donde corresponda
  • Textos alternativos en imágenes
  • Soporte para modo oscuro
  • Diseño responsive
  • Respeto por las preferencias de movimiento reducido (prefers-reduced-motion)

Limitaciones conocidas

Algunas imágenes o gráficos pueden no tener descripciones detalladas. Si encuentras alguna barrera de acceso, por favor contactame.

Contacto

Si tienes problemas para acceder a cualquier parte de este sitio, envíame un correo a eng.jurado@gmail.com.
